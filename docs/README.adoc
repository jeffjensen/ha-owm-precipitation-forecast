== Features

=== Precipitation Tracking

* *Rain Forecasts* - Hourly, daily, and 24-hour accumulation
* *Snow Forecasts* - Temperature-adjusted snow calculations
* *Multiple Locations* - Configure unlimited forecast locations
* *Flexible Updates* - Polling intervals from 15 minutes to 24 hours

=== Advanced Calculations

* *Temperature-Adjusted Snow Ratios* - Configurable liquid-to-snow conversion
* *Realistic Snow Estimates* - Based on atmospheric conditions
* *Precipitation Probability* - Chance of precipitation for each period
* *Peak Detection* - Identifies hours with maximum precipitation

=== Integration Features

* *Rich Attributes* - Chart-ready hourly and daily breakdowns
* *Health Monitoring* - Built-in integration status sensor
* *Service Calls* - Manual refresh and error clearing
* *Event Firing* - Automation-ready events
* *Rate Limiting* - Automatic API usage tracking

=== User Experience

* *UI Configuration* - Complete setup through Home Assistant UI
* *Options Flow* - Modify settings without reinstalling
* *Translations* - English translations included
* *Dashboard Ready* - Works with all standard cards

== Requirements

* Home Assistant 2024.1.0 or newer
* OpenWeatherMap API key with One Call API 3.0 access
* Internet connection for API calls

NOTE: OpenWeatherMap's One Call API 3.0 provides 1,000 free API calls per day.

== Installation

=== HACS (Recommended)

. Open HACS in Home Assistant
. Click *Integrations*
. Click the three dots (⋮) in the top right
. Select *Custom repositories*
. Add repository URL: `https://github.com/jeffjensen/ha-owm-precipitation-forecast-integration`
. Select category: *Integration*
. Click *Add*
. Search for "OWM Precipitation Forecast"
. Click *Install*
. Restart Home Assistant

=== Manual Installation

. Download the latest release from GitHub
. Extract the `owm_precipitation_forecast` folder
. Copy to your Home Assistant `custom_components` directory:
+
----
custom_components/
└── owm_precipitation_forecast/
    ├── __init__.py
    ├── manifest.json
    └── ...
----
. Restart Home Assistant

== Configuration

=== Initial Setup

. Go to *Settings* → *Devices & Services*
. Click *+ Add Integration*
. Search for "OWM Precipitation Forecast"
. Enter your configuration:
   * *API Key* - Your OpenWeatherMap API key
   * *Location Name* - Friendly name (e.g., "Home")
   * *Latitude/Longitude* - Location coordinates
   * *Enable Rain* - Track rain (default: Yes)
   * *Enable Snow* - Track snow (default: Yes)
   * *Polling Interval* - Update frequency (default: 1 hour)

=== Getting an API Key

. Visit https://openweathermap.org/api
. Sign up for a free account
. Subscribe to One Call API 3.0 (free tier: 1,000 calls/day)
. Copy your API key

WARNING: Keep your API key secure. Never share it publicly.

=== Modifying Settings

. Go to *Settings* → *Devices & Services*
. Find "OWM Precipitation Forecast"
. Click *Configure*
. Modify options:
   * Toggle rain/snow tracking
   * Change polling interval
   * Adjust snow ratios (advanced)

=== Sensor Attributes

Each precipitation sensor includes:

* `location` - Location name
* `coordinates` - Latitude and longitude
* `last_update` - Last update timestamp
* `forecast_time` - Time of forecast
* `temperature` - Current temperature
* `hourly_breakdown` - 24 hours of detailed data
* `description` - Human-readable amount (Light/Moderate/Heavy)

Health sensor includes:

* `api_calls_today` - API calls made today
* `api_calls_remaining` - Calls remaining
* `error_count` - Number of errors
* `last_error` - Most recent error message
* `last_update` - Last successful update
* `next_update` - Next scheduled update

== Temperature-Adjusted Snow Ratios

The integration uses realistic liquid-to-snow conversion ratios based on temperature:

[cols="2,2,3"]
|===
|Temperature |Ratio |Snow Type

|32°F+
|10:1
|Wet, heavy snow

|28-31°F
|12:1
|Wet snow

|24-27°F
|15:1
|Average snow

|20-23°F
|20:1
|Light snow

|15-19°F
|25:1
|Lighter snow

|10-14°F
|30:1
|Fluffy snow

|0-9°F
|40:1
|Very light snow

|Below 0°F
|50:1
|Powder
|===

TIP: These ratios can be customized in the integration options.

=== Example Calculation

With 0.1 inches of liquid precipitation:

* At 32°F: 0.1 × 10 = *1.0 inches* of wet snow
* At 20°F: 0.1 × 20 = *2.0 inches* of light snow
* At 0°F: 0.1 × 40 = *4.0 inches* of fluffy snow
* At -10°F: 0.1 × 50 = *5.0 inches* of powder

== Automation Examples

=== Heavy Rain Alert

[source,yaml]
----
automation:
  - alias: "Alert on Heavy Rain"
    trigger:
      - platform: numeric_state
        entity_id: sensor.owm_precipitation_forecast_home_next24h_rain
        above: 2.0
    action:
      - service: notify.mobile_app
        data:
          title: "Heavy Rain Expected"
          message: >
            {{ states('sensor.owm_precipitation_forecast_home_next24h_rain') }}
            inches of rain forecast in the next 24 hours.
----

== Troubleshooting

=== Integration Won't Load

*Symptoms:* Integration doesn't appear or fails to load

*Solutions:*

. Check Home Assistant logs for errors
. Verify Home Assistant version is 2024.1.0+
. Ensure integration files are in correct location
. Restart Home Assistant completely
. Check HACS for update notifications

=== API Key Invalid

*Symptoms:* Sensors show "unavailable", health sensor shows "error"

*Solutions:*

. Verify API key is correct
. Ensure One Call API 3.0 subscription is active
. Check API key hasn't expired
. Visit OpenWeatherMap dashboard to verify account status
. Try regenerating API key

=== No Data / All Zeros

*Symptoms:* Sensors show 0.0 or no precipitation

*Solutions:*

. This is normal if no precipitation is forecast
. Check OpenWeatherMap website for same location
. Verify location coordinates are correct
. Check that forecast data is available for your region

=== Rate Limit Exceeded

*Symptoms:* Health sensor shows "error", mentions rate limit

*Solutions:*

. You've exceeded 1,000 API calls per day
. Wait for daily reset (midnight UTC)
. Increase polling interval (e.g., 4 hours instead of 15 minutes)
. Consider OpenWeatherMap paid plan for more calls

=== Sensors Unavailable

*Symptoms:* Sensors show "unavailable"

*Solutions:*

. Check internet connection
. Verify OpenWeatherMap API is operational
. Check Home Assistant logs for specific errors
. Try manual refresh: `owm_precipitation_forecast.update_forecast`
. Check health sensor for error details

=== Wrong Snow Amounts

*Symptoms:* Snow calculations seem incorrect

*Solutions:*

. Verify temperature-adjusted ratios in options
. Check that temperatures are being read correctly
. Review sensor attributes for temperature data
. Adjust snow ratios if needed for your region
. Remember: ratios are estimates based on typical conditions

== Advanced Configuration

=== Custom Snow Ratios

. Go to integration options
. Select "Configure Snow Ratios"
. Adjust ratios for each temperature range
. Click "Submit"

*Valid Range:* 5.0 to 100.0

TIP: Research local snow-to-liquid ratios for your region.

=== Multiple Locations

. Add integration multiple times
. Use unique names for each location
. Each location has independent settings
. Each location counts toward API usage

*Example:*

* Home (45.0, -93.0)
* Cabin (46.5, -94.2)
* Work (44.8, -93.3)

=== Polling Interval Strategy

*For Active Monitoring:* 15-30 minutes

* Real-time updates
* Good for storm tracking
* Uses more API calls

*For General Use:* 1-4 hours (default)

* Balance of freshness and efficiency
* Recommended for most users

*For Occasional Checks:* 12-24 hours

* Minimal API usage
* Good for casual monitoring
