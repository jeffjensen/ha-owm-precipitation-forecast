= Development Setup Guide
:toc: left
:icons: font

== Prerequisites

* Python 3.11 or newer
* Git
* Virtual environment (recommended)
* Home Assistant development environment (optional but helpful)

== Setting Up Development Environment

=== 1. Clone the Repository

[source,bash]
----
git clone https://github.com/jeffjensen/ha-owm-precipitation-forecast-integration.git
cd ha-owm-precipitation-forecast-integration
----

=== 2. Create Python Virtual Environment

[source,bash]
----
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
----

=== 3. Install Development Dependencies

[source,bash]
----
make install-dev
# Or manually:
pip install -e ".[dev]"
----

This installs:
* The integration itself in editable mode
* Testing framework (pytest, pytest-asyncio, pytest-cov)
* Code formatters (Black)
* Linters (Pylint, Flake8)
* Type checker (MyPy)

=== 4. Verify Setup

Test that all tools are working:

[source,bash]
----
make all-checks
----

This runs:
* Code formatting check
* Linting
* Type checking
* Tests

All should pass with no errors.

== Testing

=== Running Tests

Run all tests:
[source,bash]
----
make test
----

Run with coverage:
[source,bash]
----
make test-cov
----

Coverage report opens in `coverage_html_report/index.html`

Run specific test:
[source,bash]
----
pytest tests/test_api.py::TestOWMAPIClient::test_fetch_forecast
----

Run with verbose output:
[source,bash]
----
pytest -vv tests/
----

=== Test Structure

Tests follow Home Assistant conventions:

[source,python]
----
import pytest
from unittest.mock import AsyncMock, patch

@pytest.mark.asyncio
async def test_api_success():
    """Test successful API call."""
    # Setup
    api = OWMAPIClient("test_key")

    # Mock external call
    with patch('aiohttp.ClientSession.get') as mock_get:
        mock_get.return_value.__aenter__.return_value.json.return_value = {
            'hourly': [],
            'daily': []
        }

        # Execute
        result = await api.fetch_forecast(44.9537, -93.0900)

        # Assert
        assert result is not None
        assert 'hourly' in result
----

== Working with the Integration

=== Testing in Home Assistant

For manual testing in actual Home Assistant:

1. Copy integration to Home Assistant config:
+
[source,bash]
----
cp -r custom_components/owm_precipitation_forecast \
  ~/.homeassistant/custom_components/
----

2. Restart Home Assistant

3. Add integration via UI with test API key

=== Understanding Entity Lifecycle

Entities are created in this order:

1. Config entry created via config flow
2. `async_setup_entry()` called in `__init__.py`
3. Coordinator created to manage API polling
4. Sensors created and registered
5. Periodic updates via coordinator

Each location is a separate config entry.

=== Adding New Features

When adding features:

1. Add constant to `const.py`
2. Add test case first (TDD approach)
3. Implement feature
4. Ensure `make all-checks` passes
5. Update documentation
6. Add entry to changelog

== Common Development Tasks

=== Adding a New Sensor

1. Define entity in `const.py`
2. Create test in `test_sensors.py`
3. Implement in `sensor.py`
4. Add to strings.json for UI
5. Update entity manager
6. Add documentation

=== Modifying Configuration Options

1. Update `const.py` with new option name
2. Update `strings.json` with UI labels
3. Update `config_flow.py` options step
4. Update tests in `test_config_flow.py`
5. Handle migration if changing existing option

=== Updating Dependencies

1. Edit `pyproject.toml` under `dependencies`
2. Run `pip install -e ".[dev]"`
3. Update requirements in `manifest.json`
4. Test thoroughly
5. Document change in PR
