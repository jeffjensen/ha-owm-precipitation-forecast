== Setting Up Development Environment

=== Prerequisites

* Python 3.11 or 3.12
* pip and virtualenv
* git
* Home Assistant (for integration testing)
* OpenWeatherMap API key (for testing)

=== Initial Setup

[source,bash]
----
# Clone the repository
git clone https://github.com/yourusername/ha-owm-precipitation-forecast.git
cd ha-owm-precipitation-forecast

# Create virtual environment
python -m venv venv
Activate venv:
  Linux: source venv/bin/activate
  Windows: venv\Scripts\activate

# Install development dependencies
pip install --upgrade pip
pip install -r requirements.txt
pip install -r requirements_test.txt

# Install the package in editable mode
pip install -e .
----

== Development Workflow

=== Running Tests

[source,bash]
----
# Run all tests
pytest

# Run with verbose output
pytest -v

# Run with coverage
pytest --cov=custom_components/ha_owm_precipitation_forecast

# Generate HTML coverage report
pytest --cov --cov-report=html
open htmlcov/index.html

# Run specific test file
pytest tests/test_owm_client.py

# Run specific test
pytest tests/test_owm_client.py::test_client_success
----

=== Code Quality

[source,bash]
----
# Format code with Black
black custom_components/ha_owm_precipitation_forecast tests

# Sort imports with isort
isort custom_components/ha_owm_precipitation_forecast tests

# Type checking with mypy
mypy custom_components/ha_owm_precipitation_forecast

# Linting with pylint
pylint custom_components/ha_owm_precipitation_forecast

# Security check with bandit
bandit -r custom_components/ha_owm_precipitation_forecast
----

=== Testing in Home Assistant

==== Option 1: Symlink (Development)

[source,bash]
----
# Create symlink to your development directory
ln -s $(pwd)/custom_components/ha_owm_precipitation_forecast \
      ~/.homeassistant/custom_components/ha_owm_precipitation_forecast

# Restart Home Assistant
# Changes will be reflected after restart
----

==== Option 2: Copy (Testing)

[source,bash]
----
# Copy to Home Assistant
cp -r custom_components/ha_owm_precipitation_forecast \
      ~/.homeassistant/custom_components/

# Restart Home Assistant
----

== Making Changes

=== Feature Development

1. Create a feature branch:
+
[source,bash]
----
git checkout -b feature/my-new-feature
----

2. Make your changes
3. Add tests for new functionality
4. Run tests and quality checks
5. Commit with clear messages:
+
[source,bash]
----
git commit -m "feat: add precipitation probability sensor"
----

6. Push and create pull request

=== Bug Fixes

1. Create a bugfix branch:
+
[source,bash]
----
git checkout -b fix/issue-123
----

2. Fix the issue
3. Add regression tests
4. Verify fix with tests
5. Commit and push

=== Commit Message Convention

Use conventional commits:

* `feat:` New feature
* `fix:` Bug fix
* `docs:` Documentation changes
* `test:` Adding or updating tests
* `refactor:` Code refactoring
* `chore:` Maintenance tasks

== Release Process

1. Update version in:
   * `custom_components/ha_owm_precipitation_forecast/manifest.json`
   * `pyproject.toml`
   * `setup.py`

2. Update CHANGELOG.md

3. Create and push tag:
+
[source,bash]
----
git tag -a v1.0.0 -m "Release version 1.0.0"
git push origin v1.0.0
----

4. GitHub Actions will automatically:
   * Run tests
   * Build packages
   * Create GitHub release
   * Upload assets

== Best Practices

* Write tests for all new code
* Maintain test coverage above 90%
* Use type hints everywhere
* Follow PEP 8 style guide
* Document complex logic
* Keep functions small and focused
* Use descriptive variable names
* Handle errors gracefully
* Log important events
