= Testing Guide
:toc:

== Overview

This integration uses pytest for testing with comprehensive coverage requirements.

== Running Tests

=== Basic Test Execution

[source,bash]
----
# Run all tests
pytest

# Run with verbose output
pytest -v

# Run specific test file
pytest tests/test_sensor.py

# Run specific test function
pytest tests/test_sensor.py::test_sensor_setup
----

=== Coverage Reports

[source,bash]
----
# Run with coverage
pytest --cov

# Generate HTML report
pytest --cov --cov-report=html

# View HTML report
open htmlcov/index.html
----

=== Watch Mode

[source,bash]
----
# Install pytest-watch
pip install pytest-watch

# Run in watch mode
ptw
----

== Test Structure

* `mock_owm_client`: Mocked API client
* `mock_config_entry`: Test configuration entry

== Writing Tests

=== Test Pattern

[source,python]
----
@pytest.mark.asyncio
async def test_feature_name(hass, mock_config_entry, mock_owm_client):
    """Test feature description."""
    # Arrange
    mock_config_entry.add_to_hass(hass)

    # Act
    result = await some_action()

    # Assert
    assert result == expected_value
----

=== Mocking

[source,python]
----
from unittest.mock import AsyncMock, patch

# Mock async function
mock_client.get_data = AsyncMock(return_value={"data": "value"})

# Patch class
with patch("module.Class") as mock_class:
    mock_instance = mock_class.return_value
    # ... test code
----

== Coverage Requirements

* *Minimum overall*: 90%
* *Critical paths*: 100%
* *Error handling*: All branches tested
* *Edge cases*: Included in tests

== Debugging Tests

[source,bash]
----
# Run with print statements visible
pytest -s

# Run with debugger
pytest --pdb

# Run last failed tests
pytest --lf

# Run tests matching pattern
pytest -k "test_sensor"
----

== Performance Testing

[source,python]
----
import pytest
import time

@pytest.mark.benchmark
def test_performance():
    """Test performance of calculation."""
    start = time.time()

    # ... test code

    duration = time.time() - start
    assert duration < 0.1  # Should complete in <100ms
----

== Common Issues

=== Async Test Failures

Ensure `@pytest.mark.asyncio` decorator is present.

=== Mock Not Working

Verify patch path matches actual import path.

=== Coverage Not Improving

Check for untested branches and add specific test cases.
