= Testing Guide
:toc: left
:icons: font

== Overview

Comprehensive testing is essential for reliability. This integration targets >75% code coverage with high-quality tests covering all scenarios.

== Testing Framework

Uses **pytest** with these plugins:

* `pytest-asyncio` - For async test support
* `pytest-cov` - For coverage reporting

Installation:
[source,bash]
----
pip install -e ".[dev]"
----

== Running Tests

=== All Tests

[source,bash]
----
make test
----

or

[source,bash]
----
pytest
----

=== Specific Test File

[source,bash]
----
pytest tests/test_api.py
----

=== Specific Test Function

[source,bash]
----
pytest tests/test_api.py::TestOWMAPIClient::test_fetch_forecast
----

=== With Verbose Output

[source,bash]
----
pytest -vv
----

=== With Coverage Report

[source,bash]
----

----

Generates HTML coverage report in `coverage_html_report/`

=== With Coverage Minimum

Test fails if coverage below threshold (75%):

[source,bash]
----
pytest --cov=custom_components/owm_precipitation_forecast --cov-fail-under=75
----

== Test Structure

=== Test Discovery

Pytest automatically finds tests matching:

* Files: `test_*.py`
* Classes: `Test*`
* Functions: `test_*`

Location: `tests/` directory

=== Test Anatomy

[source,python]
----
import pytest
from unittest.mock import AsyncMock, patch

class TestOWMAPIClient:
    """Tests for OpenWeatherMap API client."""

    @pytest.mark.asyncio
    async def test_fetch_forecast_success(self):
        """Test successful API forecast fetch."""
        # Arrange
        api = OWMAPIClient(api_key="test_key")
        mock_response = {
            'hourly': [
                {'dt': 1704585600, 'rain': {'1h': 5.0}},
            ],
            'daily': [
                {'dt': 1704585600, 'rain': 10.0},
            ]
        }

        # Act
        with patch('aiohttp.ClientSession.get') as mock_get:
            mock_get.return_value.__aenter__.return_value.json = AsyncMock(
                return_value=mock_response
            )
            result = await api.fetch_forecast(44.9537, -93.0900)

        # Assert
        assert result == mock_response
        assert 'hourly' in result
        assert 'daily' in result
----

Key pattern: **Arrange-Act-Assert (AAA)**

1. **Arrange**: Set up test data and mocks
2. **Act**: Call function being tested
3. **Assert**: Verify expected results

=== Async Testing

Tests with `async def` need `@pytest.mark.asyncio` decorator:

[source,python]
----
@pytest.mark.asyncio
async def test_async_function():
    result = await async_function()
    assert result is not None
----

=== Mocking External Calls

Mock external API calls to avoid real requests:

[source,python]
----
from unittest.mock import AsyncMock, patch

@patch('aiohttp.ClientSession.get')
async def test_with_mock(mock_get):
    """Test with mocked HTTP client."""
    # Configure mock
    mock_get.return_value.__aenter__.return_value.json = AsyncMock(
        return_value={'hourly': []}
    )

    # Test code
    api = OWMAPIClient("key")
    result = await api.fetch_forecast(0, 0)

    # Assertions
    assert result is not None
    mock_get.assert_called_once()
----

=== Error & Edge Cases

Test error handling and edge cases:

[source,python]
----
@pytest.mark.asyncio
async def test_api_timeout():
    """Test API timeout handling."""
    api = OWMAPIClient(api_key="test_key")

    with patch('aiohttp.ClientSession.get') as mock_get:
        mock_get.side_effect = asyncio.TimeoutError()

        with pytest.raises(APIError) as exc_info:
            await api.fetch_forecast(0, 0)

        assert "timeout" in str(exc_info.value).lower()

@pytest.mark.asyncio
async def test_invalid_coordinates():
    """Test invalid latitude/longitude."""
    api = OWMAPIClient(api_key="test_key")

    with pytest.raises(ValueError):
        await api.fetch_forecast(lat=100, lon=200)  # Out of range
----

* `entity_manager.py`: 85%+
* `sensor.py`: 85%+
* `config_flow.py`: 80%+ (UI logic harder to test)

Overall: 75% minimum

## Debugging Tests

=== Pytest Debugger

Stop at breakpoints:

[source,bash]
----
pytest tests/test_api.py --pdb
----

Commands in debugger:
* `n` - next line
* `s` - step into
* `c` - continue
* `l` - list code
* `p variable` - print variable

=== VSCode Debugging

1. Click "Run and Debug" in sidebar
2. Select "Python: Debug Tests"
3. Set breakpoints (click line number)
4. Test runs and stops at breakpoints
5. Inspect variables in Debug Console

=== Print Debugging

Add debug prints:

[source,python]
----
def test_something():
    result = expensive_calculation()
    print(f"Result: {result}")  # Will show in test output with -s
    assert result > 0
----

Run with print output:

[source,bash]
----
pytest -s tests/test_api.py
----

## Test Best Practices

1. **One assertion per test** (prefer, but OK to have multiple related)
2. **Clear test names** - `test_fetch_forecast_with_invalid_api_key_raises_error`
3. **Don't depend on execution order** - Tests should be independent
4. **Mock external dependencies** - Never call real APIs in tests
5. **Use fixtures** - Share common setup code
6. **Test both success and failure** - Happy path + error cases
7. **Keep tests fast** - Use mocks, avoid sleep()
8. **Document complex tests** - Explain why if non-obvious

## Examples in Code

=== Testing API Error Handling

[source,python]
----
@pytest.mark.asyncio
async def test_api_handles_rate_limit():
    """Test handling of API rate limit (429 response)."""
    api = OWMAPIClient(api_key="test_key")

    with patch('aiohttp.ClientSession.get') as mock_get:
        # Simulate rate limit response
        mock_response = AsyncMock()
        mock_response.status = 429
        mock_response.text = AsyncMock(return_value="Rate limit exceeded")
        mock_get.return_value.__aenter__.return_value = mock_response

        # Should raise APIError, not crash
        with pytest.raises(APIError) as exc_info:
            await api.fetch_forecast(44.9537, -93.0900)

        assert "rate limit" in str(exc_info.value).lower()
----

=== Testing Temperature-Adjusted Ratios

[source,python]
----
def test_snow_ratio_calculation():
    """Test snow ratio based on temperature."""
    from custom_components.owm_precipitation_forecast.data_models import (
        calculate_snow_ratio,
    )

    # Very cold
    assert calculate_snow_ratio(-5, cold_threshold=25, cold_ratio=15) == 15.0

    # Warm
    assert calculate_snow_ratio(35, warm_threshold=32, warm_ratio=5) == 5.0

    # Transitional (should interpolate)
    ratio = calculate_snow_ratio(28, cold_threshold=25, cold_ratio=15,
                                  warm_threshold=32, warm_ratio=5)
    assert 5 < ratio < 15
----
