== Overview

*OWM Precipitation Forecast* provides precise rain and snow accumulation forecasts from OpenWeatherMap's One Call API 3.0.
Calculates temperature-adjusted snow accumulation using configurable ratios (10:1, 15:1, 20:1).

*Hourly, daily, and next-24h precipitation totals* with rich attributes for Lovelace cards and automations.

== Features

* 9 precipitation sensors per location:
** Hourly, daily, next-24h totals for rain, snow, and combined
* Temperature-adjusted snow ratios (configurable presets: dry/wet snow)
* Health monitoring: dedicated binary sensor with diagnostics
* Configurable polling: 15min to 24h intervals
* Inches primary (cm convertible via attributes)
* Production-ready: >90% test coverage, GitHub Actions CI/CD
* HACS-ready: auto-updates, easy installation

== Installation

=== Via HACS (Recommended)

. Search for `OWM Precipitation Forecast` in *HACS → Integrations*
. Click *Download this repository*
. Restart Home Assistant
. *Settings → Devices & Services → + Add Integration → OWM Precipitation Forecast*

=== Manual Installation

. Download or clone this repository
. Copy `custom_components/owm_precipitation_forecast/` to `<config>/custom_components/`
. Restart Home Assistant
. *Settings → Devices & Services → + Add Integration → OWM Precipitation Forecast*

== Snow Ratio Science

Snow accumulation calculated by converting liquid precipitation with temperature-adjusted ratios:

[options="header"]
|===
|Temperature (°F) |Ratio |1" liquid → Snow
|< 0 |20:1 |20"
|0–15 |15:1 |15"
|15–32 |10:1 |10"
|> 32 |0:1 |Rain
|===

*Dry powder:* 20:1 ratio (cold, light snow) +
*Wet snow:* 10:1 ratio (near freezing, heavy)

*Custom ratios* available in Options flow.
== Troubleshooting

=== Common Issues

[cols="30%,70%",frame="topbot",options="header"]
|===
|Issue |Solution
|API key invalid
|Verify at https://home.openweathermap.org/api_keys[OWM Dashboard]

|Health: `failed`
|Check `last_api_error` attribute, verify API quota

|Health: `degraded`
|Wait for next poll (or reduce polling interval)

|Entities unavailable
|Check `binary_sensor.*_health` is `off`

|No snow forecasts
|Verify temperature < 32°F in attributes
|===
