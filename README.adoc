== Features

* ✅ *HACS Compatible* - Easy installation through HACS
* 🌧️ *Rain Tracking* - Hourly, daily, and 24-hour rain forecasts in inches
* ❄️ *Snow Tracking* - Temperature-adjusted snow accumulation predictions
* ⚙️ *Highly Configurable* - UI-based configuration with multiple options
* 📊 *Rich Data Attributes* - Detailed forecast data for charts and automations
* 🏥 *Health Monitoring* - Dedicated health sensor for integration status
* 🔄 *Flexible Polling* - Choose update intervals from 15 minutes to 24 hours
* 📏 *Multiple Units* - Native support for inches with automatic cm conversion
* 🎯 *Location Names in Entity IDs* - Easy identification of sensors
* 🔒 *Type Safe* - Full type hints and static analysis
* 🧪 *Thoroughly Tested* - 90%+ test coverage

== Installation

=== HACS (Recommended)

1. Open HACS in Home Assistant
2. Go to "Integrations"
3. Click the three dots menu (⋮) in the top right
4. Select "Custom repositories"
5. Add this URL: `https://github.com/yourusername/ha-owm-precipitation-forecast`
6. Select category: "Integration"
7. Click "Install"
8. Restart Home Assistant

=== Manual Installation

1. Download the latest release from https://github.com/yourusername/ha-owm-precipitation-forecast/releases
2. Extract the `ha_owm_precipitation_forecast` directory from the archive
3. Copy to your `custom_components` directory:
+
[source,bash]
----
cp -r ha_owm_precipitation_forecast ~/.homeassistant/custom_components/
----
+
4. Restart Home Assistant
5. Add the integration via the UI

== Quick Start

=== 1. Get an API Key

1. Sign up at https://openweathermap.org/api
2. Choose the "One Call API 3.0" (free tier: 1,000 calls/day)
3. Generate an API key
4. *Note:* New API keys may take 1-2 hours to become active

=== 2. Add the Integration

1. Go to *Settings* → *Devices & Services*
2. Click *Add Integration*
3. Search for "OpenWeatherMap Precipitation Forecast"
4. Enter your configuration:
   * *API Key*: Your OpenWeatherMap API key
   * *Latitude/Longitude*: Location coordinates (defaults to your HA location)
   * *Location Name*: Friendly name (e.g., "Home", "Cabin")
   * *Enable Rain*: Create rain sensors
   * *Enable Snow*: Create snow sensors

=== 3. Configure Options (Optional)

1. Go to *Settings* → *Devices & Services*
2. Find "OpenWeatherMap Precipitation Forecast"
3. Click *Configure*
4. Adjust settings:
   * *Update Interval*: 15min, 30min, 1hr, 4hr, 8hr, 12hr, or 24hr
   * *Enable/Disable Rain*: Toggle rain sensors
   * *Enable/Disable Snow*: Toggle snow sensors

== Temperature-Adjusted Snow Ratios

Snow accumulation is calculated using scientifically-based temperature ratios:

[cols="2,1,3"]
|===
|Temperature Range (°F) |Ratio (Snow:Rain) |Typical Conditions

|Above 32°F
|0:1
|No snow (rain only)

|28-32°F
|10:1
|Wet, heavy snow

|20-28°F
|15:1
|Normal snow

|15-20°F
|20:1
|Light, fluffy snow

|10-15°F
|30:1
|Very light snow

|Below 10°F
|40:1
|Powder snow
|===

*Example:* If 0.5 inches of liquid precipitation is forecast at 25°F, the integration calculates:
`0.5 inches × 15 = 7.5 inches of snow`

== Usage Examples

=== Automations

==== Heavy Snow Alert

[source,yaml]
----
automation:
  - alias: "Heavy Snow Alert"
    trigger:
      - platform: numeric_state
        entity_id: sensor.owm_precipitation_forecast_home_snow_next24h
        above: 6
    action:
      - service: notify.mobile_app
        data:
          title: "Heavy Snow Warning"
          message: >
            {{ states('sensor.owm_precipitation_forecast_home_snow_next24h') }}
            inches of snow expected in the next 24 hours!
      - service: light.turn_on
        entity_id: light.porch
        data:
          brightness: 255
----

==== Rain Expected Notification

[source,yaml]
----
automation:
  - alias: "Rain Expected - Close Windows"
    trigger:
      - platform: numeric_state
        entity_id: sensor.owm_precipitation_forecast_home_rain_next24h
        above: 0.5
    condition:
      - condition: state
        entity_id: binary_sensor.bedroom_window
        state: 'on'
    action:
      - service: notify.mobile_app
        data:
          message: "Rain expected! Close bedroom window."
----

==== ApexCharts Card (requires apex-charts-card)

[source,yaml]
----
type: custom:apexcharts-card
header:
  title: Hourly Precipitation Forecast
  show: true
graph_span: 24h
series:
  - entity: sensor.owm_precipitation_forecast_home_rain_hourly
    name: Rain
    type: column
    data_generator: |
      return entity.attributes.forecast.map((entry) => {
        return [new Date(entry.timestamp), entry.rain_inches];

    name: Snow
    type: column
    data_generator: |
      return entity.attributes.forecast.map((entry) => {
        return [new Date(entry.timestamp), entry.snow_inches];
      });
----

== API Rate Limits

OpenWeatherMap API limits by tier:

[cols="2,1,3"]
|===
|Tier |Calls/Day |Recommended Interval

|Free
|1,000
|1 hour or more (24 calls/day)

|Startup
|10,000
|15 minutes (96 calls/day)

|Developer
|100,000
|Any interval
|===

*Recommendation:* Use 1-hour intervals on the free tier to stay well under the limit.

== Troubleshooting

=== Integration Won't Load

1. Check API key is valid at https://home.openweathermap.org/api_keys
2. Verify API key has been active for 1-2 hours
3. Check Home Assistant logs: *Settings* → *System* → *Logs*
4. Verify internet connectivity
5. Check you're not rate-limited

=== No Data Showing

1. Wait for the first update cycle (check your poll interval)
2. Check the health sensor for status messages
3. Verify sensors are enabled in integration options
4. Restart Home Assistant
5. Check entity names match your location

=== API Rate Limit Errors

1. Increase poll interval in integration options
2. Check if you have multiple instances of the integration
3. Verify no other apps are using the same API key
4. Consider upgrading your OpenWeatherMap plan

=== Sensors Show "Unavailable"

1. Check the health sensor for error messages
2. Verify API key is still valid
3. Check Home Assistant logs for errors
4. Try reloading the integration
5. Remove and re-add the integration if issues persist
