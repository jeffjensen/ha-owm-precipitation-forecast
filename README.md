# OWM Precipitation Forecast

Home Assistant integration for OpenWeatherMap precipitation forecasts.

## Features
- Hourly rain/snow forecasts
- 24h accumulation predictions
- Temperature-adjusted snow ratios
- Multi-location support

## Installation
1. Copy to `custom_components/owm_precipitation_forecast/`
2. Restart Home Assistant
3. Configure via Settings → Devices & Services → Add Integration
